### Q: What is Hex Explorer?

Hex Explorer is an explorer I created for **RO-sploit**. It's basically an explorer similar to Dex Explorer, Vex Explorer, OpenDex, and others.

However, **Hex Explorer does NOT have a properties feature**. You can only use it to view scripts.

It's nowhere near the level of Dex Explorer, but it's still worth giving it a try! The project will continue to receive updates.

I know the UI is bad  I'm working on a revamp, so hopefully it'll look much better soon!
